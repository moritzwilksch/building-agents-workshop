# Workshop context

Build an agent that reviews employee expense submissions against a policy handbook. Each case includes a receipt and a submission note. The agent returns a reimbursement for each charge and explains the rules it applied.

Start with the Stage 0 template. Run the benchmark, inspect mistakes and tool traces in the viewer, then change one thing and try again. Compare reimbursement accuracy, failures, token use, and cost. The goal is to understand why an agent succeeds or fails, not just to improve its score.

The stages are cumulative. Each tagged checkout adds a reference approach for one more capability. Try your own approach first; use a later tag when you want an example or need to catch up. The benchmark and evaluation data are there to test your agent, not to supply its answers.
