# Viewer UI

Use this standalone palette for every viewer change. Prefer these hex values over custom color names or unavailable design-system tokens:

- **Canvas:** `#f1f5f9`
- **Surfaces:** `#ffffff`
- **Recessed areas:** `#f8fafc`
- **Primary text:** `#0f172a`
- **Body text:** `#334155`
- **Muted text:** `#64748b`; subdued text `#94a3b8`
- **Borders and dividers:** `#f1f5f9` or `#cbd5e1`
- **Primary action:** `#4f46e5`; hover `#4338ca`
- **Interactive hover/selection:** `#eef2ff` / `#e0e7ff`
- **Positive values:** `#059669`
- **Negative values:** `#dc2626`

The primary-action scale is:

| Shade | Hex |
| --- | --- |
| 50 | `#eef2ff` |
| 100 | `#e0e7ff` |
| 200 | `#c7d2fe` |
| 300 | `#a5b4fc` |
| 400 | `#818cf8` |
| 500 | `#6366f1` |
| 600 | `#4f46e5` |
| 700 | `#4338ca` |
| 800 | `#3730a3` |
| 900 | `#312e81` |
| 950 | `#1e1b4b` |

Use a purple/violet accent for AI-related elements rather than the primary action color:

- **AI highlight:** `#8b5cf6`
- **AI hover/strong highlight:** `#7c3aed`
- **AI light background:** `#f5f3ff`

Preserve readable contrast. Use color as a supporting signal, not the sole indication of state.
